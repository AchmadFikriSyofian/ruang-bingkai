# Kisah Bahagia — Website Starter

Website portfolio dan company profile Wedding Content Creator dengan gaya clean, elegant, modern, dan simple.

## Menjalankan website
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser.
3. Untuk development, disarankan memakai ekstensi Live Server di VS Code.

## Konfigurasi wajib sebelum dipublikasikan
Buka `script.js`, lalu ubah:
- `whatsappNumber`: nomor WhatsApp bisnis format internasional tanpa tanda `+`, contoh `62812...`.
- `instagramUrl`: URL Instagram resmi.

## Konten yang perlu diganti
- Ganti semua foto Unsplash dengan foto/video dokumentasi asli Kisah Bahagia.
- Perbarui harga dan fasilitas paket di `index.html`.
- Ganti testimoni contoh dengan ulasan pelanggan asli.
- Sesuaikan FAQ, area layanan, durasi coverage, dan estimasi delivery dengan kebijakan bisnis.
- Portfolio saat ini memakai gambar contoh dan modal informasi. Video/galeri asli dapat ditambahkan setelah materi tersedia.

## Struktur
- `index.html` — struktur dan konten website
- `style.css` — desain responsif
- `script.js` — interaksi, filter portfolio, modal paket, WhatsApp, dan navigasi

Website ini belum memakai backend atau admin dashboard. Perubahan harga dan portfolio masih dilakukan langsung melalui file HTML.
